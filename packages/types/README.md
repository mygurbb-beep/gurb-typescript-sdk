# @gurb/api-types

Shared request/response types for the [Gurb](https://mygurb.com) API. No runtime code.

You do not normally install this directly — [`@gurb/server`](https://www.npmjs.com/package/@gurb/server)
and [`@gurb/embed`](https://www.npmjs.com/package/@gurb/embed) both re-export what they use.

Full documentation: https://github.com/mygurbb-beep/gurb-typescript-sdk
